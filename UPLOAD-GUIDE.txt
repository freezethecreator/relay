Relay setup (no terminal needed)

A. Supabase (once)
1. Create a free project at supabase.com.
2. SQL editor: paste and run relay_schema.sql.
3. Authentication > Sign In / Providers > Email: turn OFF "Confirm email" while testing.
4. Project Settings > API: copy the Project URL and the anon public key.

B. GitHub + Vercel
1. Unzip, create an empty GitHub repo named relay, upload everything inside the folder.
2. On vercel.com, import the repo. Before clicking Deploy, open Environment Variables and add:
   NEXT_PUBLIC_SUPABASE_URL = your Project URL
   NEXT_PUBLIC_SUPABASE_ANON_KEY = your anon public key
3. Deploy. Open the link, go to /signup and create your account.

Local run (optional): copy .env.local.example to .env.local, fill it in, then npm install and npm run dev.
